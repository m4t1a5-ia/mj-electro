# MJ Electricidad

Sitio web de MJ Electricidad listo para publicar con GitHub Pages.

## Contenido

- `index.html`: página principal.
- `styles.css`: diseño, versión responsive y transiciones.
- `app.js`: catálogo, filtros, galerías y WhatsApp.
- `catalogo/`: imágenes de los 77 productos.
- `trabajos/`: 20 fotos de instalaciones realizadas.
- `media/catalogo-transicion.gif`: GIF animado del catálogo.
- `media/trabajos-realizados.mp4`: video MP4 de trabajos realizados.

La versión corregida incluye galerías con navegación, alternativa compatible
para navegadores sin soporte completo de `dialog`, animaciones al filtrar el
catálogo y transiciones adaptadas a celulares.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Descomprimí este ZIP y subí **todo su contenido** a la raíz del repositorio.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main`, la carpeta `/ (root)` y guardá.

GitHub mostrará el enlace público cuando termine la publicación.
